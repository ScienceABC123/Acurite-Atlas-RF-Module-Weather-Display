STEP 2: OS Initial Startup

  Install SD card in RaspberryPi Zero 2W and turn power on.

  The OS initial startup will take just under 2 minutes to complete. During this time the display will be
  "undefined" and there will be one automatic reboot at the login prompt before the OS initial startup completes.

  Login at the command prompt

STEP 3: Raspberry Pi Software Configuration Tool

  sudo raspi-config

  System Options
  Auto Login
  <Yes>

STEP 4: Edit config.txt

  sudo nano /boot/firmware/config.txt

  Change line from:
    dtoverlay=vc4-kms-v3d
  to:
    # dtoverlay=vc4-kms-v3d

  Add:
    # HDMI Monitor 1920x1080
    hdmi_group=2
    hdmi_mode=1
    hdmi_mode=87
    hdmi_cvt=1920 1080 60 6 0 0 0

STEP 5: Reboot

  sudo reboot

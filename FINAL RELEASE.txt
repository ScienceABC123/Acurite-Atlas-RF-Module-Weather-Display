FINAL RELEASE, sort of...

Weather Station display (1920x1080) for AcuRite Atlas weather station.

I have thought about finalizing this project for more than 2 years. The reason I haven't is because I keep adding features from time to time. I have finally come to the conclusion that I'm going to keep "tinkering" with it, indefinitely. As such I'm going to minimize what's on GitHub to just the latest version, and strip out all the historical/developmental stuff.

As for a list of features I'm going to take the lazy approach and provide print screen captures that cover an entire day (every hour on the hour, and one at 11:59 pm to capture the entire day). These print screen captures are generated by the program as BMPs. I post capture converted them from BMPs to JPGs, to save disk space (each BMP is just over 6MB, while the JPG is only 388KB.)

The "options.h" file is checked every minute on the minute to make the most common changes without having to edit the "weather16.c" source file and recompile. Items covered by the "options.h" file include:
- LATITUDE, the latitude of the AcuRite Atlas weather station
- LONGITUDE, the longitude of the AcuRite Atlas weather station
- SAVE_HR_BMP_FLAG, save a print screen capture as a BMP, every hour on the hour
- SAVE_EOD_BMP_FLAG, save a print screen capture as a BMP, at the end of the day (11:59pm)
- DEBUG_FLAG, turn on RF packet debug, display at the top left corner of the display. The information is: current second, packet type (mostly 03 and 10, and occasionally 01), packet count, packet timeout count, packet checksum error count, and empty packet count. The timeout, checksum, and empty counts are cleared at the beginning of each day.

BMPs are saved in the "/home/pi/Weather/Print_Screens/" directory.
